# Task Manager API

A RESTful Task Management API built with FastAPI and MongoDB.

## Setup

1. Clone the repo
2. Create a virtual environment
3. Install dependencies: `pip install -r requirements.txt`
4. Copy `.env.example` to `.env` and configure
5. Run: `uvicorn app.main:app --reload`

## API Documentation

Once running, visit `/docs` for Swagger UI or `/redoc` for ReDoc.
